# 点句翻译

考研英语二阅读精读工具。**纯静态**，双击 `site/index.html` 即可使用，不需要服务器、不需要安装任何东西。

## 功能

| 功能 | 说明 |
|---|---|
| **点句划成分** | 点击任意句子 → **就在句子下方**展开主语/谓语/宾语/状语/表语/各类从句等成分，逐块配色标注并附语法说明。就地展开不遮挡任何文字，上下文始终可见 |
| **原站解析页** | 精讲句在原站有独立解析页，句内链接可直接打开（Ctrl/⌘+点击 或中键），面板内也有入口。非精讲句那边无页面，故不给死链 |
| **重点词加粗** | 段内重点单词与词组加粗显示（取自 PDF 高频词表 + 词组搭配），**鼠标悬浮即显释义** |
| **精讲句画线** | PDF「真题句逐层精讲」选中的句子在原文下画线，点击可看考点讲解 |
| **中英对照** | 英文一段、中文一段，**译文默认常显**且按正文样式排，读起来是一篇正常文章而非题面；顶栏「只看英文」可临时隐藏译文 |
| **高频词表** | PDF 真题高频词，含 CEFR 等级、词性、释义、本篇词频、真题句频，表头可排序、支持筛选 |

```
site/
  index.html               页面骨架
  style.css                样式（含深色模式、窄屏单栏）
  app.js                   全部逻辑（原生 JS，无依赖）
  data/
    library.js             篇目清单 —— 新增篇目改这里
    2016-text1.js          2016 Text 1 数据（window.PASSAGE），共 44 个

  extract.py               从 PDF 提取素材（段落/译文/精讲句/词表/URL）
  gen_t{年}_{篇}.py         每篇的生成器（校验 bold / chunks 是否真实存在于原句）
```

## 为什么必须是普通 `<script>` 而不是 `fetch`

双击打开时页面走 `file://` 协议，浏览器会以 CORS 为由**拦截 `fetch()` 读取本地 JSON**，页面会直接空白。因此数据以 `window.PASSAGE = {...}` 的普通脚本形式注入，这也是 `app.js` 里不使用 `import` / `export` 的原因。改动时请保持这一点。

## 新增一篇（例如 2017 Text 1）

1. 提取 PDF：`pdftotext -layout -enc UTF-8 "真题.pdf" work/txt/2017.txt`
2. 在 `work/gen.py` 中以同样的方式填写该篇的 `zh` / `insight` / `note` / `bold` / `chunks`
3. 运行 `python work/gen.py`，产出 `site/data/2017-text1.js`
4. 在 `site/data/library.js` 里加一行：

   ```js
   { id: '2017-1', label: '2017 考研英语二 · Text 1', file: 'data/2017-text1.js' }
   ```

`gen.py` 会自动校验：每个 `bold` 子串和每个 `chunks.text` 都必须真实存在于原句中，且成分按出现顺序排列，否则报错——防止手写数据打错字。

## 关于数据来源（重要）

成分划分**并非来自 PDF**。本地这批 PDF 印自 `english-exam.lazynote.cn`，其网页版句子解析页含结构树，但**打印成 PDF 时那一层数据丢失了**——PDF 里只有文字点评（如「第一个分句的强调句结构易被误判为主系表」），没有逐词的成分标注。因此本项目的成分划分为逐句生成。

PDF 中**确实有**且被本项目直接采用的数据：原文、逐段中文翻译、真题句精讲及其考点文字、高频词表。
